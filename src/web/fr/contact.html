Contact

Un bug ? Une idée ? Le moyen le plus rapide de nous joindre est GitHub Issues.

Veuillez saisir votre nom.

Veuillez saisir une adresse e-mail valide.

Veuillez décrire votre demande (au moins 10 caractères).

À l'envoi, une issue GitHub pré-remplie s'ouvre dans un nouvel onglet pour que vous puissiez la vérifier avant de l'envoyer. Aucune donnée n'est stockée sur ce site.

D'autres façons de nous joindre

  • 🐛 Ouvrir une issue directement — idéal pour les bugs et les demandes de fonctionnalités.
  • 📖 GitHub Discussions — demandez à la communauté.
  • ⭐ Dépôt GitHub — code source, versions et documentation (repo : frabbat3/MarkOut).
Conseils pour une réponse rapide. Pour les problèmes d'extraction, indiquez la phase en échec (détection / OCR) et, si possible, un petit PDF d'exemple. Les captures de la vue de débogage aident beaucoup.
