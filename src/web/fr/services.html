Fonctionnalités

Tout ce que MarkOut sait faire — gratuit, privé et entièrement dans l'onglet de votre navigateur.

🟡

Extraction des surlignages

Un modèle YOLO26 personnalisé détecte visuellement les zones surlignées sur chaque page — fonctionne avec des surlignages faits dans Acrobat, Preview, Edge ou tout autre lecteur, même si le PDF ne conserve pas les annotations.

🔍

Support des PDF scannés

La même pipeline neuronale traite aussi les PDF image-only et les captures d'écran : un seul flux pour chaque document, numérique ou scanné.

📝

OCR dans le navigateur

PaddleOCR reconnaît le texte de chaque fragment, auto-hébergé et utilisable hors ligne — le texte ne quitte jamais votre machine.

📄

Export Markdown propre

Les surlignages sortent dans l'ordre de lecture, groupés par page et section, avec front-matter YAML et identifiants citables stables.

🤖

Sortie prête pour les LLM

Le Markdown exporté est conçu comme base pour les assistants IA : structure stable, identifiants par ligne, notes sur la qualité d'extraction.

🛡️

100 % privé

Aucun envoi, aucun compte, aucun serveur. Le traitement est local ; à la fin, modèles et fichier sont libérés de la mémoire.

À qui cela s'adresse

  • Étudiants — transformez les articles surlignés en notes de révision en quelques secondes.
  • Chercheurs — constituez un corpus propre de passages issus de nombreux PDF, prêt pour l'analyse ou les workflows LLM.
  • Rédacteurs et éditeurs — collectez citations et références sans retaper.
  • Personnes soucieuses de leur vie privée — tout document, sensible ou non, reste sur votre appareil.

Plateformes

MarkOut fonctionne sur tout navigateur moderne avec WebAssembly : Chrome, Firefox, Edge, Safari 16+. Le bureau offre l'accélération WebGPU optionnelle ; le mobile utilise une pipeline optimisée pour la mémoire. Aucune installation, aucun compte, aucun plugin.

Gratuit pour toujours. Pas d'inscription, pas de paywall, pas de limite de documents. Si MarkOut vous est utile, pensez à mettre une étoile sur GitHub.
