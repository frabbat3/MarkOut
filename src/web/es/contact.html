Contacto

¿Encontraste un error? ¿Tienes una idea? La forma más rápida de contactarnos es GitHub Issues.

Por favor, introduce tu nombre.

Por favor, introduce un correo electrónico válido.

Por favor, describe tu solicitud (al menos 10 caracteres).

Al enviar, se abre una issue de GitHub rellenada en una pestaña nueva para que la revises antes de enviarla. No se almacena ningún dato en este sitio.

Otras formas de contactarnos

  • 🐛 Abrir una issue directamente — ideal para errores y peticiones de funciones.
  • 📖 GitHub Discussions — pregunta a la comunidad.
  • ⭐ Repositorio de GitHub — código fuente, versiones y documentación (repo: frabbat3/MarkOut).
Consejos para una respuesta rápida. Para problemas de extracción, indica la fase en la que falló (detección / OCR) y, si es posible, un pequeño PDF de ejemplo. Las capturas de la vista de depuración ayudan mucho.
