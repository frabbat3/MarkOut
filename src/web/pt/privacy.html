Política de privacidade

Em resumo: seus PDFs nunca saem do seu dispositivo. Não existe um backend para onde enviá-los.

Última atualização: agosto de 2025

1. Tratamento de dados

O MarkOut é um aplicativo totalmente client-side. Quando você envia um PDF, o arquivo é lido pelo PDF.js no seu navegador e processado localmente: renderização, detecção de destaques (YOLO26 ONNX) e OCR (PaddleOCR) rodam todos na aba do navegador, via WebAssembly ou WebGPU.

  • Seu PDF nunca é transmitido — nem para nós, nem para terceiros.
  • Nenhuma conta é necessária e nenhum perfil é criado.
  • Nenhum registro da sua atividade é armazenado.

2. Armazenamento local

O site guarda algumas pequenas preferências no localStorage do seu navegador (que permanece no seu dispositivo e pode ser limpo a qualquer momento nas configurações do navegador):

  • markout-theme — sua escolha de tema claro/escuro;
  • markout-webgpu — se você desativou a aceleração de GPU;
  • markout-cookie-banner — que você fechou o aviso informativo.

Nenhum cookie é usado para rastreamento ou publicidade. Não há scripts de analytics, nem fingerprinting, nem integrações de terceiros executadas neste site.

3. Hospedagem

Este site é hospedado no GitHub Pages (GitHub, Inc.). A simples entrega da página pode envolver os logs de servidor padrão gerenciados pelo GitHub, sujeitos à declaração de privacidade do GitHub. Os modelos de IA usados pela ferramenta são auto-hospedados na mesma origem.

4. Links para terceiros

O site aponta para serviços externos — principalmente GitHub (código-fonte, issues, botão de estrela). Ao sair deste site, aplicam-se as políticas de privacidade desses serviços. O formulário de contato abre uma issue do GitHub pré-preenchida somente após seu clique em enviar.

5. Privacidade de crianças

O MarkOut não coleta nenhum dado pessoal e é seguro para todos: não há nada para consentir nem nada para excluir.

6. Alterações nesta política

Se esta política mudar, a data de "última atualização" acima será revisada. Como a ferramenta não armazena dados pessoais, nenhum processo de notificação é necessário.

7. Contato

Dúvidas sobre privacidade? Abra uma issue no repositório do GitHub ou consulte a página de contato.
