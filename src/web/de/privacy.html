Datenschutzerklärung

Kurzfassung: Deine PDFs verlassen nie dein Gerät. Es gibt kein Backend, an das sie gesendet werden könnten.

Zuletzt aktualisiert: August 2025

1. Datenverarbeitung

MarkOut ist eine vollständig clientseitige Anwendung. Wenn du ein PDF hochlädst, wird die Datei von PDF.js in deinem Browser gelesen und lokal verarbeitet: Rendering, Markierungserkennung (YOLO26 ONNX) und OCR (PaddleOCR) laufen alle im Browser-Tab, per WebAssembly oder WebGPU.

  • Dein PDF wird nie übertragen — weder an uns noch an Dritte.
  • Kein Konto erforderlich und kein Profil wird erstellt.
  • Keine Logs deiner Aktivität werden gespeichert.

2. Lokale Speicherung

Die Website speichert einige kleine Einstellungen im localStorage deines Browsers (bleibt auf deinem Gerät und kann jederzeit in den Browsereinstellungen gelöscht werden):

  • markout-theme — deine Design-Wahl (hell/dunkel);
  • markout-webgpu — ob du die GPU-Beschleunigung deaktiviert hast;
  • markout-cookie-banner — dass du das Hinweisbanner geschlossen hast.

Keine Cookies werden für Tracking oder Werbung verwendet. Es gibt keine Analytics-Skripte, kein Fingerprinting und keine Drittanbieter-Einbettungen, die auf dieser Website ausgeführt werden.

3. Hosting

Diese Website wird auf GitHub Pages gehostet (GitHub, Inc.). Das bloße Ausliefern der Seite kann Standard-Serverlogs umfassen, die von GitHub verwaltet werden und der GitHub-Datenschutzerklärung unterliegen. Die KI-Modelle sind auf derselben Herkunft selbst gehostet.

4. Links zu Dritten

Die Website verlinkt externe Dienste — hauptsächlich GitHub (Quellcode, Issues, Stern-Button). Sobald du diese Website verlässt, gelten die Datenschutzrichtlinien dieser Dienste. Das Kontaktformular öffnet erst nach deinem Klick auf „Senden" eine vorbefüllte GitHub-Issue.

5. Datenschutz von Kindern

MarkOut erhebt keine personenbezogenen Daten und ist für alle sicher nutzbar: Es gibt nichts, dem zugestimmt werden müsste, und nichts zu löschen.

6. Änderungen an dieser Erklärung

Falls sich diese Erklärung ändert, wird das Datum „Zuletzt aktualisiert" oben angepasst. Da das Tool keine personenbezogenen Daten speichert, ist kein Benachrichtigungsverfahren erforderlich.

7. Kontakt

Fragen zum Datenschutz? Öffne eine Issue im GitHub-Repository oder nutze die Kontaktseite.
