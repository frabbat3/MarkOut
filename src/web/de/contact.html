Kontakt

Einen Fehler gefunden? Eine Idee? Der schnellste Weg zu uns ist GitHub Issues.

Bitte gib deinen Namen ein.

Bitte gib eine gültige E-Mail-Adresse ein.

Bitte beschreibe deine Anfrage (mindestens 10 Zeichen).

Beim Senden öffnet sich eine vorbefüllte GitHub-Issue in einem neuen Tab, die du vor dem Absenden prüfen kannst. Auf dieser Website werden keine Daten gespeichert.

Weitere Kontaktwege

  • 🐛 Direkt eine Issue öffnen — am besten für Fehler und Feature-Wünsche.
  • 📖 GitHub Discussions — frag die Community.
  • ⭐ GitHub-Repository — Quellcode, Releases und Dokumentation (Repo: frabbat3/MarkOut).
Tipps für eine schnelle Antwort. Bei Extraktionsproblemen nenne die Phase, in der es fehlschlug (Erkennung / OCR), und wenn möglich ein kleines Beispiel-PDF. Screenshots der Debug-Ansicht helfen sehr.
