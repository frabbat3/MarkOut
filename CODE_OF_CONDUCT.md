# Code of Conduct

MarkOut is a small open-source project. Let's keep it a pleasant place.

## The short version

- Be respectful and assume good faith.
- Give constructive feedback; accept it gracefully.
- No harassment, no insults, no trolling, no spam.
- Keep discussions on-topic.

## Enforcement

Project maintainers may remove comments, issues or contributions that
violate these rules, and may block repeat offenders. If you experience or
witness unacceptable behavior, report it privately via a GitHub issue in
the repository.
